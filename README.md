## Тема проекта № 20 — Генератор лабиринтов и поиск пути

Проект — программа на Java (Swing, без сторонних библиотек), которая наглядно визуализирует алгоритмы генерации лабиринтов и поиска пути. Лабиринт генерируется алгоритмами Depth-first и Kruskal, кратчайший путь ищется алгоритмами BFS и A\*. Пользователь задаёт размер лабиринта (до 256×256), точки старта и финиша, скорость анимации и алгоритм, видит пошаговую работу алгоритмов и получает метрики: время выполнения и число проверенных ячеек. Любой алгоритм поиска можно запустить повторно на том же лабиринте.

Документация проекта (сбор требований, User Story Map, UML-диаграммы) находится в папке [docs](docs/PR2.md).
